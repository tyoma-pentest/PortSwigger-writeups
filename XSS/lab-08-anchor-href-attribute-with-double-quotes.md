#   Stored XSS into anchor href attribute with double quotes HTML-encoded

**Сложность:** Apprentice  
**Тема:** XSS  
**Ссылка:** [PortSwigger](https://portswigger.net/web-security/cross-site-scripting/contexts/lab-href-attribute-double-quotes-html-encoded)  

## 1. Описание уязвимости

Эта лаборатория содержит сохраненную уязвимость сценариев кросс-сайта в функциональности комментария.

---

## 2. Разведка

Открыл лабораторную - сайт с блогами. Под блогами можно оставлять комментарии. Чтобы решить эту лабораторию, надо отправить комментарий, который звонит `alert` функция при нажатии на имя автора комментария.

![Решения](images/Screenshot_2026-10-13_23_09_04.png)

---

## 3. Ход решения

Нашёл форму комментариев на странице поста. В поле `Website` подставил payload `javascript:alert(1)`. Оставил комментарий. При клике на имя автора (которое обернуто в тег `<a>` с атрибутом `href`) сработал JavaScript-код `alert(1)`. Лаба решена.

![Решения](images/Screenshot_2026-10-22_21_47_08.png)

![Решения](images/Screenshot_2026-10-22_21_47_42.png)

---

## 4. Причина уязвимости

Приложение сохраняет введенный URL (поле `website`) и вставляет его в атрибут `href` ссылки на имя автора. Хотя двойные кавычки экранируются, протокол `javascript:` не блокируется. При клике на ссылку браузер выполняет JavaScript-код.
